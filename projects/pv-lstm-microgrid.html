Adaptive P-Q Control of PV Generators in Microgrids Based on LSTM Forecasting for Enhanced Stability

MATLAB/Simulink Python LSTM Microgrid Control

Developed an adaptive control strategy using LSTM-based load forecasting for photovoltaic generators, implemented in Simulink to enhance grid stability, power quality, and dynamic response in microgrid applications with high PV penetration.

Key contributions

  • Integrated a deep learning-based LSTM model for accurate short-term load forecasting using historical data from PGCB and DPDC.
  • Designed an enhanced P-Q control algorithm that dynamically adjusts active (P) and reactive (Q) power output of PV inverters based on forecasted load data.
  • Implemented MPPT with Perturb & Observe algorithm and dq-frame current control for grid synchronization and maximum power extraction.
  • Validated the proposed method through MATLAB/Simulink simulations under sudden load changes, PV fluctuations, and grid disturbances.
  • Demonstrated improved voltage and frequency stability, faster response time, and better power quality in the microgrid.

Methodology & design

  • Data acquisition & preprocessing: Hourly load and generation data from PGCB (Mar 2021 – Jun 2023) and DPDC (Dec 2006 – Nov 2010) were collected and preprocessed for model training.
  • LSTM load forecasting: A recurrent neural network with long short-term memory cells was trained to predict short-term load demand using past load values and time-based features.
  • Enhanced P-Q control: Forecasted load values feed into a dq-frame current controller, adjusting Id and Iq references to manage active and reactive power injection.
  • MPPT: Perturb & Observe algorithm tracks the maximum power point of the PV array under varying irradiance and temperature conditions.
  • Clarke & Park transformations: Three-phase abc quantities are converted to αβ stationary frame and then to dq rotating reference frame for decoupled control.

Outcomes & evaluation

  • Voltage & frequency stability: Improved under fluctuating irradiance and sudden load changes with the adaptive P-Q control strategy.
  • Tracking accuracy: LSTM model achieved MAE of 2.41% and RMSE of 3.70% relative to typical load (~14,000 MW).
  • Power quality: Reduced overshoot and oscillations in real power and frequency response.
  • Responsiveness: Enhanced dynamic response to grid disturbances in both grid-connected and islanded modes.
  • Sustainability: Reduces reliance on fossil-fuel backup generators by improving PV utilization and lowering carbon emissions.
  • Responsible AI: Ensures unbiased forecasting and system transparency without compromising user privacy.
