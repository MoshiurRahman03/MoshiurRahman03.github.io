Automated Sudoku Solver Using Image Processing in MATLAB

MATLAB Image Processing Toolbox OCR Backtracking Algorithm

Built an end-to-end Sudoku solver that reads a puzzle directly from a photograph, extracts the 9×9 digit matrix through classical image-processing techniques (grayscale conversion, binarization, connected-component analysis, and OCR), solves it with a recursive backtracking algorithm, and overlays the solution back onto the original image.

Context & motivation

The project explores how digital images can be treated as 2D signals f(x, y) — sampled and quantized into finite M×N matrices of pixel intensities. It brings together image-processing fundamentals (color-space conversion, binarization, morphological and connectivity operations) with classical AI search (backtracking) to solve a well-defined constraint-satisfaction problem: Sudoku.

Rather than manually transcribing a puzzle, the system takes a photo of a printed Sudoku, automatically recognizes the digits, reconstructs the puzzle matrix, and produces a solved, annotated image.

Key contributions

  • Designed a complete image-to-matrix pipeline: RGB → grayscale → binary, connected-component extraction, grid removal, and cell-wise OCR.
  • Automated extraction of the Sudoku puzzle from a raw photograph by locating the largest 8-connected component and cropping it to the grid boundary.
  • Implemented an OCR step (MATLAB ocr with a digit-only character set) to recognize each cell and build the 9×9 puzzle matrix.
  • Implemented a recursive backtracking solver with row, column, and 3×3 subgrid validity checks.
  • Overlaid solved digits back onto the original image using pixel coordinates derived from cell geometry.

Methodology

Image processing pipeline

  1. Load the colored (RGB) input image.
  2. Convert RGB → grayscale → binary using thresholding.
  3. Extract the largest connected component (8-connectivity) and level it to isolate the Sudoku grid.
  4. Eliminate the grid lines using logical OR with a grid-only image.
  5. Split the region of interest into 81 cells; strip 10 boundary pixels per cell for safety.
  6. Run OCR on each cell to recognize the digit (0 if empty), then assemble the 9×9 Sudoku matrix.

Sudoku solving

  1. Find the next empty cell in the puzzle.
  2. Try digits 1–9 in that cell, checking validity against the row, column, and 3×3 subgrid.
  3. Recurse on the updated puzzle. On failure, backtrack and try the next digit.
  4. When no empty cells remain, the puzzle is solved.

Overlay & rendering

Solved digits are written back onto the original image with red text and a transparent box, positioned cell-by-cell using subImageWidth and subImageHeight offsets — only for cells that were originally empty.

Core algorithm — validity check 

function isvalid = isvalid(matrix, row, col, digit)
  % Check row and column
  if any(matrix(row, :) == digit) || any(matrix(:, col) == digit)
    isvalid = false; return;
  end
  % Check 3x3 subgrid
  subgridRowStart = 3 * floor((row - 1) / 3) + 1;
  subgridColStart = 3 * floor((col - 1) / 3) + 1;
  subgrid = matrix(subgridRowStart : subgridRowStart + 2, ...
                   subgridColStart : subgridColStart + 2);
  if any(subgrid(:) == digit)
    isvalid = false; return;
  end
  isvalid = true;
end

Image fundamentals applied

  • Digital image representation: an image is a 2D signal f(x, y), sampled in space and quantized in amplitude to produce an M×N matrix of pixel values.
  • Color spaces: RGB images store three matrices (R, G, B), each 0–255; grayscale stores a single intensity matrix 0–255; binary stores only 0 or 1.
  • Connectivity: 4-connected and 8-connected component analysis used to isolate the Sudoku grid from the background.
  • Morphological / logical operations: OR-combining binary masks to suppress grid lines while preserving digits.
  • Resizing: the cleaned binary image is normalized (e.g. 450×450) so cell boundaries are uniform for OCR.

Outcomes & evaluation

  • End-to-end automation: from a photograph to a solved, annotated image with no manual digit entry.
  • Robust extraction: largest connected-component + grid-removal reliably isolates the puzzle from background clutter.
  • OCR accuracy: digit-only character set ('0123456789') with 'Word' text layout yields accurate recognition on clean, printed puzzles.
  • Correctness of solver: backtracking with row/column/subgrid validity produces a unique correct solution for standard Sudoku puzzles.
  • Clean visualization: overlay writes only into originally empty cells, so the solved digits are visually distinguishable from the given clues.

Limitations & future work

  • OCR performance degrades on heavily skewed, low-resolution, or hand-written Sudoku inputs.
  • Assumes a single, well-framed Sudoku grid occupies the largest connected component of the image.
  • Robustness could be improved with adaptive thresholding, perspective correction, and a CNN-based digit classifier.
  • The solver could be extended to detect and report invalid or multi-solution puzzles.
