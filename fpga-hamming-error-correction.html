Error Correction in a 32-bit Message Using FPGA

FPGA Verilog Hamming Code

Implemented Hamming code error detection and correction on FPGA using Verilog.

Key contributions

  • Designed and implemented a Hamming code encoder/decoder in Verilog for a 32-bit message.
  • Synthesized and deployed the design on FPGA hardware.
  • Verified single-bit error detection and correction functionality through simulation and hardware testing.
