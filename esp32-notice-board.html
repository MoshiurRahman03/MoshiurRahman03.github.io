ESP32-Based Smart Notice Board with IoT Interface

ESP32 UART RTC Module IoT Protocols

Built an IoT-enabled smart notice board using UART communication for data transfer and wireless protocols for remote updates, with an RTC module for time-based scheduling and real-time notifications.

Key contributions

  • Implemented UART-based data transfer between the controller and display hardware.
  • Enabled wireless, remote message updates over the internet via the ESP32's IoT connectivity.
  • Integrated an RTC module for accurate time-based scheduling of notifications.
