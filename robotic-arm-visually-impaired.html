Academic Project

Car-Mounted 6-DOF Robotic Arm for Visually Impaired Users

Raspberry Pi 6-DOF Robotic Arm Ultrasonic Sensors Python

Programmed a 6-DOF robotic arm on Raspberry Pi, integrating ultrasonic, touch, and camera feedback with motor control algorithms for obstacle detection and navigation assistance.

Key contributions

  • Programmed a 6-DOF robotic arm controller on a Linux-based Raspberry Pi system.
  • Integrated ultrasonic, touch, and camera sensor feedback for obstacle detection.
  • Developed motor control algorithms to assist navigation for visually impaired users.
