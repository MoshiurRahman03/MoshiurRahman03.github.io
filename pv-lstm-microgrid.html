Adaptive P-Q Control of PV Generators in Microgrids Based on LSTM Forecasting

MATLAB/Simulink Python LSTM

Developed an adaptive control strategy using LSTM-based power forecasting for photovoltaic generators, implemented in Simulink to enhance grid stability, power quality, and dynamic response in microgrid applications.

Key contributions

  • Trained an LSTM model in Python to forecast short-term photovoltaic power output.
  • Fed forecasted values into a Simulink-based adaptive P-Q control scheme for PV inverters.
  • Evaluated improvements in grid stability and power quality under fluctuating irradiance conditions.
